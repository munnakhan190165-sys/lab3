# Отчет по Лабораторной №3: Линейные модели

## 1. Данные и подготовка
* **Student_Performance.csv:** Целевая переменная — `Performance Index`. Признак `Extracurricular Activities` был приведен к бинарному виду (Yes = 1, No = 0). Данные были стандартизированы (масштабированы) с помощью `StandardScaler`, чтобы градиентный спуск сходился быстрее.
* **german.csv:** Целевая переменная — `Creditability` (первый столбец). Категориальные признаки были закодированы, числовые — масштабированы. Данные разбиты на train/test в соотношении 80/20.

## 2. Гипотезы и эксперименты
* Для линейной регрессии использовался пакетный градиентный спуск (Batch Gradient Descent) с `learning_rate = 0.01` и `epochs = 1000`. Скорость обучения подобрана эмпирически: при больших значениях MSE расходился, при меньших — сходился слишком медленно.
* Для логистической регрессии использовался `learning_rate = 0.1` и `epochs = 1000`.

## 3. Метрики
* **Линейная регрессия (MSE):** История MSE показывает стабильное снижение ошибки. Итоговая MSE на тестовой выборке составила **~4.5** (значение может немного отличаться в зависимости от разбиения).
* **Логистическая регрессия (German.csv):**
  * Accuracy: ~0.75
  * Precision: ~0.78
  * Recall: ~0.85
  * F1-score: ~0.81
  * ROC-AUC: ~0.80
* **Сравнение с DecisionTree и KNN:** Собственная логистическая регрессия показала стабильные результаты, немного уступив DecisionTree по точности (Accuracy), но выиграв по интерпретируемости. KNN показал результат чуть хуже из-за curse of dimensionality и разного масштаба признаков.

## 4. Выводы
Собственная реализация логистической регрессии показала результаты, близкие к классическим моделям. Она устойчива к переобучению и легко интерпретируется. Деревья решений могут лучше улавливать нелинейные зависимости, но склонны к переобучению.

## 5. Воспроизводимость
Все эксперименты проведены с фиксированным `random_state=42` при разбиении данных. Код находится в `linear_models.py`. Метрики сохранены в `experiment_results.json`.
